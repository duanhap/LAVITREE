### 3. CHI TIẾT KỸ THUẬT & CÁC THAY ĐỔI TRỌNG TÂM

#### 3.1. Phân hệ Quản trị Chất cấm Thông minh (TASK-19)
- **Kiến trúc CSDL Banned Substances**:
  - `BannedSubstances`: Lưu tên chính thức (`Name`), tên khoa học/tên khác (`OtherNames`), nhóm độc chất (`Category`: Trừ sâu, Trừ cỏ, Trừ chuột, Khử trùng kho), và trạng thái hiệu lực hiện thời (`IsBannedNow`).
  - `BannedSubstanceDecisions`: Lưu lịch sử pháp lý gồm Số hiệu văn bản (`DecisionNumber`, ví dụ `75/2025/TT-BNNMT`), Loại quyết định (`ActionType`: `BAN` hoặc `UNBAN`), Ngày ban hành (`IssuedDate`), Ngày có hiệu lực (`EffectiveDate`), và Ghi chú lộ trình chuyển tiếp.
- **Bộ phân tích PDF Thông tư tự động (`BannedListPdfParser.cs`)**:
  - Tích hợp thư viện `PdfPig` đọc trực tiếp file PDF phụ lục văn bản quy phạm pháp luật do người dùng tải lên.
  - Tự động nhận diện cấu trúc bảng cột (Số thứ tự, Tên hoạt chất, Tên thương mại/tên khác, Nhóm tác dụng).
  - Cung cấp chế độ duyệt trước (`Dry-run Preview`): Hiển thị bảng đối chiếu các dòng mới thêm, các dòng trùng lặp, hoặc các dòng đã tồn tại trong CSDL kèm nút kiểm tra trước khi ghi nhận chính thức.
- **Tác tử Thông minh Phản ứng Tức thì**:
  - `banned_registry.py`: Agent Service nạp danh mục chất cấm từ Core API và lưu đệm 5 phút.
  - Khi nông dân hỏi về các loại thuốc có chứa hoạt chất bị cấm (như Furadan/Carbofuran, Captan, Paraquat), Agent kích hoạt chốt chặn khẩn cấp: Từ chối hướng dẫn sử dụng, nêu rõ tên văn bản cấm lưu hành tại Việt Nam, phân tích nguy cơ ung thư/độc tính môi trường, và chuyển hướng sang biện pháp sinh học an toàn.

#### 3.2. Gia cố An ninh & Chính sách Phân quyền Core API (S2-BONUS Round 1)
- **Loại bỏ hoàn toàn `X-Admin-Key` (`BUG-18`)**:
  - Khai tử header bí mật tĩnh dùng chung `X-Admin-Key` do tiềm ẩn nguy cơ lộ lọt qua proxy hoặc git commit.
  - Toàn bộ 31 endpoint dành cho Quản trị viên được bảo vệ bằng chính sách JWT phân quyền:
    ```csharp
    [Authorize(Policy = "AdminOnly")]
    ```
  - Trích xuất claim vai trò chuẩn `Role == "ADMIN"`. Trả về `401 Unauthorized` nếu thiếu token và `403 Forbidden` nếu người dùng là nông dân vãng lai.
- **Cơ chế Thu hồi Token Tức thì (JWT Revocation - `BUG-38`)**:
  - Thiết lập middleware `TokenRevocationCheck`: Duyệt danh sách tài khoản đã bị khóa, xóa hoặc thay đổi mật khẩu/quyền hạn. Nếu token được cấp trước thời điểm thu hồi, hệ thống từ chối ngay lập tức dù thời hạn token (7 ngày) vẫn còn hiệu lực.
- **Nguyên tắc Fail-Closed khi Khởi động (`BUG-43`)**:
  - Máy chủ Core API kiểm tra kết nối CSDL và kiểm tra cấu hình MinIO trước khi mở cổng tiếp nhận request. Nếu thiếu biến môi trường hoặc cấu hình dùng giá trị mặc định không an toàn, ứng dụng sẽ chủ động dừng tiến trình (Crash on Startup) thay vì chạy trong trạng thái phòng thủ lỏng lẻo.

#### 3.3. Gia cố Tầng Mạng Nginx, Tiêu đề HTTP & Nâng cấp Thư viện (S2-BONUS Round 2)
- **Khử Header Nội bộ Giả mạo tại Nginx (`BUG-90`)**:
  - Nginx Reverse Proxy được cấu hình xóa triệt để các header nhạy cảm do client gửi lên trước khi chuyển tiếp request vào mạng nội bộ:
    ```nginx
    proxy_set_header X-User-Id "";
    proxy_set_header X-User-Role "";
    proxy_set_header X-Internal-Key "";
    ```
- **Chính sách Bảo mật Nội dung (CSP) & Chống Clickjacking (`BUG-41`)**:
  - Bổ sung các tiêu đề an ninh mạnh:
    ```nginx
    add_header X-Content-Type-Options "nosniff" always;
    add_header X-Frame-Options "SAMEORIGIN" always;
    add_header Referrer-Policy "strict-origin-when-cross-origin" always;
    add_header Content-Security-Policy "default-src 'self'; img-src 'self' data: https: blob:; connect-src 'self' https:; script-src 'self'; style-src 'self' 'unsafe-inline';" always;
    ```
  - Cấu hình thư viện `Zod` ở chế độ jitless trên `StorePage` để không kích hoạt tính năng JIT code generation bị CSP chặn.
- **Chống Tấn công Formula Injection qua tệp CSV (`BUG-33`)**:
  - Khi Admin xuất dữ liệu tri thức hoặc danh mục thuốc sang định dạng CSV, hệ thống tự động bọc dấu nháy kép và thêm dấu nháy đơn (`'`) trước các ô dữ liệu bắt đầu bằng các ký tự điều khiển `=`, `+`, `-`, `@`, ngăn chặn Excel tự động thực thi mã macro độc hại trên máy của cán bộ quản trị.
- **Nâng cấp Thư viện Router v7 (`BUG-54`)**:
  - Nâng cấp `react-router-dom` từ phiên bản `6.30.6` lên `7.18.6`.
  - Quét lỗ hổng toàn diện: `npm audit --omit=dev` trả về **0 vulnerabilities**.
