### 3. CHI TIẾT KỸ THUẬT & CÁC THAY ĐỔI TRỌNG TÂM

#### 3.1. Pha 1: Nạp bài báo toàn văn & Trích xuất siêu dữ liệu thông minh
- **Quy trình hoạt động**:
  - Quản trị viên chỉ cần sao chép toàn bộ văn bản bài viết từ trang tin khuyến nông hoặc viện nghiên cứu và dán vào form `/admin/ingest`.
  - Core API chuyển tiếp văn bản sang Agent Service (`POST /internal/knowledge/label-paragraphs`). Mô hình ngôn ngữ lớn (Gemini 2.x / Flash-Lite) thực hiện song song 2 nhiệm vụ:
    1. Gán nhãn phân loại cho từng đoạn: `SYMPTOMS` (Triệu chứng), `PREVENTION` (Phòng ngừa), `TREATMENT` (Điều trị), `PRACTICE` (Biện pháp canh tác), hoặc loại bỏ đoạn rác.
    2. Bóc tách siêu dữ liệu bài báo: `title`, `organization`, `publication_year`, `disease_prediction`.
- **Chốt chặn bản quyền Điều 25 Luật SHTT**:
  - Giới hạn cứng: Quản trị viên chỉ được chọn tối đa **8 đoạn trích**.
  - Tổng số ký tự trích dẫn nguyên văn không được vượt quá $\max(1200, 30\% \times \text{tổng độ dài bài viết})$.
  - Lưu trữ nguyên văn `IsVerbatim = true` vào CSDL PostgreSQL, phục vụ trích dẫn minh bạch cho nông dân khi hỏi đáp.

#### 3.2. Pha 2: Quản lý Thư viện Ảnh triệu chứng thực địa (`KnowledgeImage`)
- **Thiết kế CSDL Entity `KnowledgeImage`**:
  ```csharp
  public class KnowledgeImage : BaseEntity
  {
      public Guid Id { get; set; }
      public string ClassCode { get; set; } = string.Empty; // Mã bệnh mục tiêu
      public string ImageUrl { get; set; } = string.Empty;   // Đường dẫn MinIO hoặc URL ngoại bộ
      public string? PlantPart { get; set; }                // Leaf, Stem, Fruit, WholePlant
      public string? SymptomDescription { get; set; }       // Mô tả triệu chứng trực quan
      public string? SourceCredit { get; set; }             // Bản quyền / Tác giả ảnh
      public bool IsVerified { get; set; } = false;         // Đã thẩm định bởi Admin
  }
  ```
- **Xử lý tệp tin an toàn**:
  - Khi Admin upload ảnh thực địa lên MinIO, hệ thống tự động bóc tách và xóa sạch thẻ EXIF (vị trí GPS, thông tin thiết bị máy ảnh) nhằm bảo vệ quyền riêng tư người chụp ảnh.
  - Hỗ trợ nhập trực tiếp liên kết ảnh HTTPS từ các nguồn học thuật uy tín.
  - Tích hợp thư viện ảnh vào Sổ tay bệnh học (`HandbookPage.tsx`) giúp nông dân đối chiếu trực quan triệu chứng bệnh trên đồng ruộng.

#### 3.3. Pha 3: Đề xuất Vật tư nông nghiệp (`ProductSuggestion`) & Hoàn thiện bảng `Products`
- **Thực thể `ProductSuggestion`**:
  - Khi phân tích đoạn trích thuộc loại `TREATMENT`, Agent tự động phát hiện các thực thể có tên thương mại hoặc hoạt chất (ví dụ: `Ridomil Gold 68WG`, `Antracol 70WP`, `Trichoderma`).
  - Gợi ý được lưu vào bảng `ProductSuggestions` ở trạng thái `PENDING` kèm trích đoạn ngữ cảnh nguyên văn.
- **Nâng cấp bảng `Products`**:
  - Thêm trường `Availability`: enum `IN_STOCK` (còn hàng tại kho Lavitree), `OUT_OF_STOCK` (hết hàng), `NOT_SOLD` (thuốc/vật tư khuyến cáo nông dân mua ngoài thị trường, Lavitree không kinh doanh trực tiếp).
  - Thêm `InfoSourceUrl`: URL trang tra cứu nhãn thuốc hoặc hướng dẫn kỹ thuật của Cục Bảo vệ thực vật.
  - Hỗ trợ `PhiDays = NULL` và `ActiveIngredient = NULL` đối với vật tư nông nghiệp thông thường (vôi bột, bạt nilon, bẫy dính màu).
- **Rà soát & Gia cố Chốt chặn (Review Fixes)**:
  - Sinh lại migration EF Core bằng công cụ chính thống `dotnet-ef migrations add 20261111080000_AddProductSuggestionsAndRefineProducts` kèm Designer hoàn chỉnh.
  - Bổ sung `CHECK constraint`: Bắt buộc thuốc BVTV (hóa học, sinh học) phải có thời gian cách ly `PhiDays`, nghiêm cấm thuốc BVTV để `PhiDays` rỗng.
  - Core API tự động kiểm tra đối soát chuỗi `MentionText` có xuất hiện nguyên văn trong đoạn trích hay không, triệt tiêu nguy cơ AI bịa tên thuốc.
  - Đồng bộ danh mục hoạt chất cấm giữa hệ thống backend Core API, giao diện Admin và bộ lọc Guardrails của Agent Service.

#### 3.4. Vá lỗi Đăng xuất trong Chat & Cải thiện Chat UX
- **Vá lỗi phiên đăng nhập**:
