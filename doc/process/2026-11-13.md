  - Khi người dùng thay đổi giá trị trong ô `URL bài báo` hoặc dán một đoạn văn bản mới, hàm dọn dẹp sẽ kích hoạt để đặt lại toàn bộ state (`title`, `organization`, `publicationYear`, `diseasePrediction`).
  - Giải thích rõ ràng nguyên nhân nút "Lưu bài báo" bị vô hiệu hóa (chưa chọn bệnh mục tiêu, vượt quá hạn mức trích dẫn ký tự, hoặc chưa chọn đoạn trích nào).
  - Loại bỏ hoàn toàn quy tắc CSS `font-serif`. Hệ thống sử dụng đồng nhất fontsans `@fontsource/be-vietnam-pro`, giúp hiển thị hoàn hảo dấu thanh tiếng Việt xếp chồng.
- **Phía Agent Service (`pipeline.py`)**:
  - Bổ sung cơ chế `Exponential Backoff Retry` (3 lần thử lại) đối với Gemini API client khi gặp lỗi mạng tạm thời hoặc quá tải hạn ngạch (429/503), khống chế trong thời gian timeout 12 giây.
  - Tinh chỉnh Prompt chỉ đạo: Tuyệt đối không lấy mẫu "2024" nếu bài báo không đề cập đến năm; không nhận diện các danh từ chỉ tác nhân gây bệnh (nấm, vi khuẩn, virus) thành tên thuốc BVTV.
- **Phía Core API (`KnowledgeController.cs`)**:
  - Tự động gộp các tiêu đề mục ngắn (`< 80` ký tự) vào đầu đoạn văn tiếp theo để bảo toàn ngữ cảnh học thuật.
  - Lọc bỏ dòng liên hệ, số điện thoại hotline, quảng cáo khỏi danh sách đoạn phân tích.

#### 3.2. Tính năng Chia đoạn Tương tác & Quản lý Thẻ Mentions (`TASK-15-R3`)
- **Dialog Chia đoạn Tương tác (`SplitParagraphDialog`)**:
  - Khi một đoạn văn bản có độ dài vượt quá 800 ký tự (vượt ngưỡng hiển thị tối ưu của một chunk RAG), Admin bấm nút "Tách đoạn".
  - Thuật toán tự động tìm dấu chấm câu (`.`, `!`, `?`, `;\n`) gần điểm chính giữa đoạn văn nhất để phân chia thành 2 phần con: `Phần A` và `Phần B`.
  - Cả 2 phần con đều có checkbox riêng, nhãn phân loại riêng và thẻ mentions độc lập, cho phép chọn lọc linh hoạt trước khi lưu.
- **Biên tập Thẻ Vật tư / Hoạt chất (`Mentions Editor`)**:
  - Cho phép Admin xóa bỏ các thẻ AI trích xuất sai bằng nút `✕`.
  - Thay đổi phân loại thẻ qua menu ngữ cảnh: Hóa học (`CHEMICAL`), Sinh học (`BIOLOGICAL`), Vật tư (`SUPPLY`), Canh tác (`PRACTICE`).
  - Hỗ trợ thêm cụm từ mới bằng cách bôi đen văn bản trong đoạn trích hoặc nhập thủ công (được kiểm tra chặt chẽ tính nguyên văn trong RAM).
- **Trực quan hóa Trạng thái Reindex**:
  - Thay thế cửa sổ hiển thị JSON thô bằng Dialog hiển thị 3 chỉ số chính:
    1. Tổng số đoạn tri thức đã được vector hóa trong ChromaDB.
    2. Thời điểm đồng bộ thành công gần nhất.
    3. Trạng thái hàng đợi xử lý nền (`IDLE`, `PROCESSING`, `SUCCESS`).

#### 3.3. Quy trình Sửa bài báo Đã lưu từ Duyệt tri thức (`TASK-15-R4`)
- **Luồng hoạt động `/admin/ingest?edit=<url>`**:
  - Tại bảng Duyệt tri thức (`/admin/knowledge`), mỗi bài viết có nút "Sửa bài". Khi bấm, hệ thống chuyển sang giao diện Ingest với tham số query `?edit=<encoded_url>`.
  - Hệ thống tự động gọi API `GET /api/v1/knowledge/sources/by-url` để lấy toàn bộ siêu dữ liệu và danh sách các đoạn trích đã lưu trong CSDL.
  - Trường URL bị khóa (chống đổi URL làm sai lệch nguồn).
  - Các đoạn trích đã lưu từ trước được hiển thị với huy hiệu màu xanh lục `"Đã lưu"`. Quản trị viên chỉ có thể thay đổi phân loại thẻ hoặc đánh dấu xóa. Nếu sửa đổi nội dung văn bản của đoạn nguyên văn, API sẽ từ chối với lỗi `HTTP 400 Bad Request` nhằm tuân thủ nguyên tắc toàn vẹn bản quyền.
  - Hỗ trợ dán bổ sung nội dung toàn bài để nạp thêm các đoạn mới chưa từng trích dẫn. Hạn mức 8 đoạn và 30% độ dài được tính lũy kế trên toàn bộ số đoạn của URL đó.

#### 3.4. Củng cố API Backend (`MedicinesController`, `KnowledgeController`)
- Bổ sung các API hỗ trợ cập nhật sản phẩm thuốc, lọc trùng lặp gợi ý vật tư trong kho hàng.
- Endpoint `POST /api/v1/knowledge/sources/batch-delete` hỗ trợ xóa mềm hàng loạt và gửi sự kiện đồng bộ lại bộ nhớ vector sang FastMCP Agent Service.
